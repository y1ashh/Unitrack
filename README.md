# University Tracker

A responsive, source-aware university and programme research workspace built from the provided editorial university references.

## Run locally

The app is self-contained and has no build dependency:

```bash
ruby -run -e httpd . -p 4173
```

Then open `http://127.0.0.1:4173/index.html`.

## Included product surface

- Discovery search and composable filters
- University profiles and programme detail pages
- Domestic/international admissions views with qualification-country context
- Costs with official / estimated / unavailable labels
- Scholarship discovery with published eligibility checklists
- Programme comparison
- Saved items and application tracker
- How to apply, International students and Student life guides
- Source and verification metadata on high-value records

The seeded records are a transparent front-end dataset. Final deadlines, eligibility, tuition and visa requirements should always be confirmed on the linked official source.
